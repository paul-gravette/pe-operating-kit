# PE Operating Kit

Practical templates for **CEOs, PE operators, and deal teams** who need clarity under time pressure — not another 40-page framework deck.

## The problem

Post-close, most value creation fails for boring reasons: no written 100-day plan, board packs that hide the ball, LP updates that read like marketing, and diligence that never forces a clear *pursue / pause / pass*.

This kit is the opposite: short files you can copy into Notion, Google Docs, or email and fill in the same day.

## Who this is for

- **CEOs** (especially PE-backed) who need a clean operating and board rhythm
- **PE operators / value-creation leads** running 100-day plans across portfolio companies
- **Deal teams & founders** doing buy-side diligence or preparing for it
- **LPs and serious investors** who want to see how operators *should* report

## What’s inside

| Path | Use it for |

| [`checklists/buy-side-diligence-questions.md`](checklists/buy-side-diligence-questions.md) | High-signal questions before you write a CIM-length memo |

## How to use

1. **Pick one file** that matches the decision in front of you this week.
2. **Copy it** into your working system (don’t leave it as a GitHub tab).
3. **Fill every blank with an owner and a date** — empty cells are the real risk.
4. **Cut sections** that don’t change a decision. Shorter is better.

## Principles

- One owner beats a RACI chart nobody opens
- Numbers without a cadence are decoration
- Writing forces the call; meetings are optional
- Templates earn their keep if a CEO would use them under stress
